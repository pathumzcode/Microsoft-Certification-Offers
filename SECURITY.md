# Security policy

This repository is documentation, not the LevelUp service, and its maintainers cannot investigate or resolve vulnerabilities in LevelUp, Microsoft, Pearson VUE, or other third-party systems.

## Reporting a security concern in this repository

Do not publish exploit details, credentials, personal data, or active voucher codes in a public issue. If the repository host offers private vulnerability reporting, use that feature. Otherwise, contact the repository maintainer through a security contact they have published. No private reporting address is configured by this project yet.

For account, voucher, course, or platform incidents, contact the official service through the [LevelUp Helpdesk](https://skillupwithlevelup.com/support). For security issues affecting another provider, use that provider's own security reporting channel.

## Safe disclosure

Do not access accounts or systems without authorization, test production systems, or include real secrets in reports. Share only the minimum information needed for the maintainer to understand the concern.

## Supported versions

There are no software releases or supported application versions for this documentation project. Corrections to current documentation are welcome through the normal contribution process when they do not expose sensitive information.
